# Registro de decisões

Uma decisão por arquivo, numerada: `0001-titulo-curto.md`.

Formato mínimo:

```
# 0001 — Título

Data | Status: aceita | revisada | revertida

## Contexto
O que provocou a decisão.

## Decisão
O que foi decidido.

## Consequências
O que fica mais fácil, o que fica mais difícil, o que fica impossível.

## Alternativas descartadas
Cada uma com o motivo. Este é o campo que evita re-debater daqui a seis meses.
```

Registre também os **sensores reprovados**: o que foi testado, com que números,
por que reprovou. Sem isso você reinventa o mesmo sensor daqui a oito meses.
